# Font licenses — Raw design system

Raw ships two font families in `fonts/`. Keep these notices with the files wherever they are copied, including the website repository.

## Charter

`Charter-Regular.woff2`, `Charter-Italic.woff2`, `Charter-Bold.woff2`, `Charter-BoldItalic.woff2` — the Charter fonts Bitstream contributed to the X Consortium, as packaged in `charter-webfont` 4.1.0. Modified for Raw in one respect: the descent values in the `hhea` and `OS/2` tables were stored as positive numbers, which made browsers set every line too low, and are now negative.
